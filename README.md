
# Student Placement Planner & Tracker

## About the Project
A menu-driven C++ application that helps students organize placement preparation, track DSA progress, manage tasks, plan daily study activities, and maintain revision history.

## Features
- Student profile management
- DSA topic progress tracker
- Task management using a linked list
- Daily study planner using a queue
- Revision history using a stack
- File handling to save progress
- Input validation

## Data Structures Used
- Array: DSA progress
- Linked List: Task management
- Queue: Daily study planner
- Stack: Revision history

## Requirements
- C++ compiler supporting C++17
- Git for version control

## How to Compile
```bash
g++ -std=c++17 main.cpp -o planner
```

## How to Run
On Windows:
```bash
planner.exe
```
